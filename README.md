# ItemSwap

**ItemSwap** — клиентский мод для Minecraft 1.16.5 (Forge), который автоматически управляет инструментами и расходными предметами в инвентаре.

---

## Возможности

### 🔨 Отслеживание инструментов (`tool`)

```
/itemswap tool <предмет> <слот>
```

**Пример:**
```
/itemswap tool diamond_axe 3
```

- В слоте **3** хотбара будет отслеживаться **алмазный топор** (вне зависимости от зачарований и названия).
- Как только инструмент будет изношен на **90%** (потерял 90% прочности), мод автоматически **поменяет его местами** с другим топором из инвентаря, у которого износ ниже 90%.

---

### 🌱 Отслеживание расходников (`consumable`)

```
/itemswap consumable <предмет> <слот>
```

**Пример:**
```
/itemswap consumable spruce_sapling 1
```

- **Все слоты основного инвентаря** (кроме хотбара) будут заполнены хотя бы по одному указанному предмету.
- В **слоте 1 хотбара** также будет этот предмет.
- Когда предмет в слоте 1 заканчивается, мод автоматически **переносит** стак из основного инвентаря в слот 1 хотбара.

---

### 🚫 Сброс отслеживания

```
/itemswap clear
```

Отключает всё отслеживание.

---

## Установка

1. Установите [Minecraft Forge 1.16.5](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.16.5.html) (рекомендуется 36.2.x).
2. Скопируйте `.jar` мода в папку `mods/` вашего клиента Minecraft.
3. Запустите игру.

---

## Сборка из исходников

Требования: **JDK 8**, **Gradle** (или использовать прилагаемый `gradlew`).

```bash
./gradlew build
```

Готовый файл появится в `build/libs/itemswap-1.0.0.jar`.
